Syrics

Download lyrics from Spotify

✓ Extension ready!
No configuration needed. The extension automatically captures Spotify's authentication tokens for seamless lyrics downloading.

How to use:

  1. Make sure you're logged into Spotify Web Player
  2. Navigate to any track, playlist, or album
  3. Play a song or interact with the page to activate token interception
  4. Click the three dots (⋯) next to any track
  5. Select "Download lyrics" from the menu
  6. Choose where to save the LRC file

Note: The extension intercepts Spotify's authentication tokens automatically - no manual configuration required!
