# Syrics Extension

A browser extension that allows you to download lyrics from spotify.

## Status

🚧 **This extension is currently in heavy development** 🚧

The extension is being actively developed and may have incomplete features or bugs. Use at your own discretion.

## Features (In Development)

- Download lyrics from supported music platforms
- Clean and simple interface
- Cross-platform browser support

## Installation

This extension is not yet published to browser stores. Development builds can be loaded manually for testing purposes.
