# Syrics Extension Icons

This folder should contain the extension icons in PNG format:

- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels) 
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can use the icon.svg file as a template and convert it to PNG using any image editor or online converter.

## Quick Setup:
1. Open icon.svg in any vector graphics editor (Inkscape, Illustrator, etc.)
2. Export as PNG at the required sizes
3. Place the PNG files in this folder

Alternatively, you can use online converters like:
- https://convertio.co/svg-png/
- https://svgtopng.com/

The icon should represent lyrics/music download functionality with Spotify's green theme colors (#1db954, #1ed760).
